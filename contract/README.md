# CredChain Soroban Contract

The on-chain half of CredChain: institution registration, certificate issuance,
verification, and revocation on Stellar Soroban.

## Structure

```text
contract/
├── Cargo.toml
├── Makefile
├── src/
│   ├── lib.rs          # Contract implementation
│   └── test.rs         # Unit tests
└── test_snapshots/     # Golden files generated by `cargo test`
```

Single crate, `credchain`, built as both `lib` and `cdylib`. There is no workspace.

## Commands

```bash
cargo test                            # run the unit tests
cargo test test_full_lifecycle        # run one test
cargo fmt --check                     # formatting gate (CI enforces this)
cargo clippy -- -D warnings           # lint gate (CI enforces this)
stellar contract build                # build the wasm32v1-none WASM
```

`make build`, `make test`, `make fmt`, `make deploy`, and `make clean` wrap the same commands.

CI additionally asserts the compiled WASM stays under Soroban's 64 KB limit.

## Deployment

Deployment goes through [`../client/scripts/deploy.sh`](../client/scripts/deploy.sh),
which builds, deploys, and regenerates the TypeScript bindings.

**The contract takes a constructor argument.** `__constructor(admin)` binds the admin
address as part of the deploy operation itself. Deploying without it would leave the
`Admin` slot unset, and the first caller of `configure_fees` could claim it. The deploy
script passes it automatically:

```bash
stellar contract deploy \
  --wasm target/wasm32v1-none/release/credchain.wasm \
  --source dev \
  --network testnet \
  -- \
  --admin <ADMIN_G_ADDRESS>
```

## Storage layout

Keyed by the `DataKey` enum:

- **persistent** — `Institution(Address)`, `Certificate(u64)`; TTL extended on every write
- **instance** — `NextCertId`, `InstitutionList`, `Admin`, `TokenAddress`, `TreasuryAddress`, `RegFee`

Certificate IDs come from a monotonic `NextCertId` counter starting at 1.

`register_institution` follows checks-effects-interactions: all storage writes complete
before the optional inter-contract token transfer, which only fires when `TokenAddress`,
`TreasuryAddress`, and a positive `RegFee` have all been set via `configure_fees`.

## Error codes

`ContractError` values are returned as `Error(Contract, U32(n))`:

| n | Variant |
|---|---|
| 1 | `NotRegistered` |
| 2 | `AlreadyRegistered` |
| 3 | `NotAuthorized` |
| 4 | `CertificateNotFound` |
| 5 | `AlreadyRevoked` |
| 6 | `InvalidInput` |

These are mirrored in `client/src/lib/error-decoder.ts` and pinned by tests in
`client/src/lib/error-decoder.test.ts`. Reordering this enum will fail those tests.

## Events

Emitted with short topic symbols that the frontend event listener matches on literally:

| Topic | Event |
|---|---|
| `inst_reg` | `InstitutionRegisteredEvent` |
| `cert_iss` | `CertificateIssuedEvent` |
| `cert_rev` | `CertificateRevokedEvent` |

## Test snapshots

`cargo test` writes golden files to `test_snapshots/`. Adding or renaming a test
creates or orphans a snapshot file — review the diff before committing.
